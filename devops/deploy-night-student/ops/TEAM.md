## Rotation des 3 incidents obligatoires

- Incident 01 : A = Incident Commander, B = Navigator, C = Scribe
- Incident 02 : B = Incident Commander, C = Navigator, A = Scribe
- Incident 03 : C = Incident Commander, A = Navigator, B = Scribe

## Roles

- **Incident Commander** : garde la vue d'ensemble, choisit la prochaine action et fait reformuler l'hypothese avant de toucher au systeme.
- **Navigator** : lit les logs, inspecte les fichiers et propose des pistes. Il ne modifie rien sans l'annoncer.
- **Scribe** : note la timeline, les commandes utiles, les hypotheses et le moment du retablissement.

Pour les bonus, choisissez librement la rotation, mais changez de pilote a chaque incident.
